# Carbon Impact Dashboard

A sustainability platform for tracking emissions across electricity, travel, food, and waste. It helps users manage university or campus teams, compare reduction scenarios, and generate reports.

## Features

- User accounts and profiles
- Team and campus account support
- Carbon calculator with calculation factors
- Interactive dashboard with emissions by category and trends
- Reduction planner for comparing scenarios
- Goals, challenges, and progress tracking
- Team leaderboard
- Downloadable reports

## Tech stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Prisma + PostgreSQL
- Recharts
- NextAuth-ready structure

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Project structure

- `app/` — application pages and routes
- `components/` — reusable UI and dashboard components
- `lib/` — calculations and utility logic
- `prisma/` — Prisma schema
